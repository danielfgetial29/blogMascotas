# Bienestar de los Peludos

**Bienestar de los Peludos** es un blog web informativo creado para ayudar a las personas que desean adoptar una mascota o que ya tienen una en casa. El proyecto busca brindar información clara y organizada sobre la elección, cuidado y convivencia responsable con las mascotas.

El sitio contará con **3 páginas principales**: cómo elegir una mascota, cómo cuidarla y cómo crear un vínculo adecuado con ella. El proyecto será desarrollado siguiendo las etapas de planificación, análisis, diseño, implementación y pruebas.
